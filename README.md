# Samish River Outlook

Live page: chance the Samish River (USGS 12201500, Burlington) crosses the shellfish-harvest rise trigger in the
next 3 days, with NOAA's river forecast (NWRFC SMRW1), NWS rain forecast and NOAA tide predictions.
Static site; every viewer's browser fetches the public feeds directly. Public data only.
Planning aid. The Washington Department of Health makes all closure and reopening decisions.
